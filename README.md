# PR assets

Images referenced from pull request descriptions in this fork. Not part of the
library; kept on an orphan branch so they don't appear in PR diffs.

- `pr2/`: schematic figures for #2 (exact run-length indexing along smooth
  paths). Generated by `pr2/make_figs.py` (plain Python, writes SVG) and
  rendered to PNG with headless Chromium. Geometry follows H3's hex-plane
  convention (unit spacing between centers, pointy-top hexagons); distances
  such as the margin are exaggerated for legibility.
